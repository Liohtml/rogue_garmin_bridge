# Security

The app only talks to the bike over Bluetooth LE and writes FIT files on the watch.
It makes no network requests and stores no personal data.

If you find a security problem (e.g. in the build or release pipeline), please do not
open a public issue. Report it privately via
[GitHub security advisories](https://github.com/Liohtml/rogue_garmin_bridge/security/advisories/new).
